МОЙ ЕЖЕДНЕВНИК — PWA ДЛЯ IPHONE 15
====================================

Состав пакета:
- index.html — ежедневник
- manifest.webmanifest — сведения об установленном приложении
- service-worker.js — кэширование для офлайн-открытия
- icon-192.png, icon-512.png, icon-maskable-512.png — иконки
- apple-touch-icon.png — иконка для iPhone/iOS

ВАЖНО
Google Диск может хранить эти файлы, но не публикует HTML как приложение.
Чтобы Safari мог установить ежедневник на экран «Домой», файлы нужно разместить
на HTTPS-хостинге статических сайтов. Например, GitHub Pages или Netlify.
После публикации откройте веб-адрес в Safari на iPhone.

КАК УСТАНОВИТЬ НА IPHONE
1. Опубликуйте все файлы из папки пакета в корне одного сайта по HTTPS.
2. Откройте адрес сайта именно в Safari.
3. Нажмите «Поделиться» (квадрат со стрелкой вверх).
4. Выберите «На экран Домой». Если пункт не виден, прокрутите список вниз
   или откройте «Изменить действия».
5. Если доступен переключатель «Открывать как веб-приложение», включите его.
6. Нажмите «Добавить». Иконка «Ежедневник» появится на экране Домой.

КАК ОПУБЛИКОВАТЬ ЧЕРЕЗ GITHUB PAGES (бесплатный вариант)
1. На GitHub создайте новый репозиторий.
2. Загрузите в репозиторий ВСЕ файлы из этой папки, не меняя их имена.
3. В репозитории откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch,
   затем ветку main и папку /(root), нажмите Save.
5. Дождитесь публикации и откройте выданный HTTPS-адрес в Safari на iPhone.

ЛОКАЛЬНОЕ СОХРАНЕНИЕ
Записи сохраняются в локальном хранилище браузера (localStorage) для конкретного
адреса сайта и устройства. Не очищайте данные сайта и периодически используйте
кнопку «Экспорт». Установка иконки сама по себе не синхронизирует записи
между устройствами. Для синхронизации понадобится отдельная облачная база данных.

ОБНОВЛЕНИЯ
Если заменяете файлы на хостинге, приложение обновит кэш при следующем открытии.
Если обновление не появилось, закройте приложение полностью и откройте снова.
